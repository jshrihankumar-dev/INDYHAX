# Success Criteria

## Product Success

- User can generate a message in under 60 seconds
- Output sounds human and not AI-generated
- Output is under 5 sentences
- User understands why the message works
- User gets an honest warning about possible outcomes
- Demo works without needing a long explanation

## Hackathon Success

- The bridge theme is obvious
- Judges understand the impact quickly
- The live demo has a clear before-and-after
- The visual design feels memorable
- Team can explain what was built technically
- MVP is finished before polish starts

## Demo Success

The best demo should show a user going from hesitation to a concrete message they could actually send.
