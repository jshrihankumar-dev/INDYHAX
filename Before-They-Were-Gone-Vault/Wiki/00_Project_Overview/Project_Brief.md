# Project Brief

## Name

Before They Were Gone

## Theme Connection

Hackathon theme: **Bridge**

This project interprets a bridge as a tool for reconnecting people. The user is on one side, someone they lost contact with is on the other, and the app helps create the first message that crosses the gap.

## One-Sentence Description

An AI-assisted reconnection tool that helps people write thoughtful, low-pressure messages to someone they drifted away from.

## Problem

Many people want to reconnect with someone but avoid doing it because they do not know how to start. The longer the silence lasts, the harder the first message feels.

## Solution

The app asks for context about the relationship, time apart, reason for drifting, closeness, and desired tone. It then generates:

- A short reconnection message
- A one-sentence explanation of why the message works
- A warning about what the user should be emotionally prepared for

## Target Users

- Students who lost touch with friends
- Family members after tension or distance
- Former teammates or classmates
- People moving to new schools, cities, or life stages
- Anyone who wants to reconnect but feels awkward starting

## Main Value

The product does not just generate text. It reduces emotional friction and helps people take the first step.
