# Feature Scope

## MVP Features

- Relationship context form
- Tone selector
- Claude-generated reconnection message
- Explanation of why the message works
- Warning about what to prepare for
- Copy-to-clipboard button
- Toast notification after copying
- Animated bridge visual
- Example autofill button

## Input Fields

- Name or label for the person
- Relationship
- Closeness from 1 to 10
- Why the user drifted away
- How long it has been
- Desired tone

## Tone Options

- Warm
- Casual
- Formal
- Humorous

## Output Sections

- Message
- Why this works
- Be prepared for

## Out of Scope for MVP

- User accounts
- Storing private relationship data on a server
- Sending messages directly through the app
- Backend database
- Complex authentication
- Long-term conversation coaching
